# やさいっこ畑

顔のついた野菜「やさいっこ」を育てて、引っこぬいて、直売所で売る放置ゲームです。
ブラウザだけで動きます。インストールは要りません。

## 遊び方

スマホでの操作に合わせて作っています。画面の下のボタンで「畑・直売所・台所・強化・ノート（お願い・実績・図鑑）」を切りかえます。

- **畑**：時間がたつと、やさいっこが土から顔を出します。指でなでるように横になぞると、まとめて収穫できます。3本以上まとめて抜くと、ときどき「おまけ」でもう1本もらえます。
- **倉庫**：収穫した子は倉庫にたまります。いっぱいになると収穫できなくなります。
- **直売所**：倉庫の子を棚に並べると、お客さんが買いに来ます。値札は「安め／ふつう／強気」から選べます。吹き出しに出ている「欲しい子」が棚にあると、お客さんは喜んで3割増しで買ってくれます。
- **評判**：喜んで帰るお客さんが多いほど評判が上がり、お客さんが増えます。
- **お天気**：雨のあいだは育つのが2倍、虹のあいだはめずらしい子が出やすくなります。
- **品種改良・スプリンクラー・レジ・お品書き**：売値、育つ速さ、お客さんの回転、料理の売値を上げる強化です。
- **トラクター**：一定時間ごとに畑を端から端まで走って、育った子をまとめて回収します。続けて抜くほどコンボが伸びて、走り終わるとコンボボーナスがもらえます。どの畑でも、留守中も働きます。
- **出荷トラック**：倉庫がいっぱいになると、棚にない子を半値で自動で卸します。
- **台所**：やさいっこを組み合わせて料理を作ります（全14品）。料理は材料の約3倍の値段で売れます。コンロを増やしたり、料理人さんに「おまかせ調理」を頼んだりできます。
- **季節**：春夏秋冬が10分ごとにめぐります。季節ごとの旬の子は1.3倍で売れて、景色も変わります。
- **農園ランク**：収穫・販売・お願い・新発見で経験値がたまり、ランクが上がります。ランクごとに売値が3%ずつ上がり、称号やごほうび、畑やお店の飾り（風車、看板ねこ、花壇、ちょうちん、金色の看板）が増えます。
- **町の人のお願い**：「だいこんを5本ほしいな」のような依頼が届きます。倉庫からわたすと、ふつうに売るよりずっと多いお礼がもらえます。
- **実績**：収穫数、売上、お願い、コンボなど12種類の目標があり、段階ごとにごほうびを受け取れます。
- **きらきら**：まれに金色に光るやさいっこが生えます。抜くと大きなボーナスがもらえ、きらきら図鑑に記録されます。
- **特売タイム**：ときどき1種類が特売になり、1.5倍で売れます。お客さんもその子を欲しがります。
- **図鑑**：全32種。ひとつの畑の子をすべて見つけると、その畑の売値が1.5倍になります。

畑は全部で5つあります（プランター、家庭菜園、段々畑、月の畑、砂丘の畑）。

## 音

BGMと効果音は、ブラウザの Web Audio で鳴らしています。音声ファイルは使っていません。
画面右上のボタンで、それぞれオン・オフできます。曲は、畑・月の畑・砂丘の畑・直売所でそれぞれ変わります。

## 動かし方

`index.html` をブラウザで開くだけで遊べます。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを選んでください。

## セーブ

進み具合は、ブラウザの localStorage に保存されます。別の端末やブラウザとは共有されません。
