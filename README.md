# やさいっこ畑

顔のついた野菜「やさいっこ」を育てて、引っこぬいて、直売所で売る放置ゲームです。
ブラウザだけで動きます。インストールは要りません。

## 遊び方

- **畑**：時間がたつと、やさいっこが土から顔を出します。指でなでるように横になぞると、まとめて収穫できます。3本以上まとめて抜くと、ときどき「おまけ」でもう1本もらえます。
- **倉庫**：収穫した子は倉庫にたまります。いっぱいになると収穫できなくなります。
- **直売所**：倉庫の子を棚に並べると、お客さんが買いに来ます。値札は「安め／ふつう／強気」から選べます。吹き出しに出ている「欲しい子」が棚にあると、お客さんは喜んで3割増しで買ってくれます。
- **評判**：喜んで帰るお客さんが多いほど評判が上がり、お客さんが増えます。
- **農家さん**：畑ごとに雇えます。留守中も収穫してくれます。
- **お天気**：雨のあいだは育つのが2倍、虹のあいだはめずらしい子が出やすくなります。
- **図鑑**：全32種。ひとつの畑の子をすべて見つけると、その畑の売値が1.5倍になります。

畑は全部で5つあります（プランター、家庭菜園、段々畑、月の畑、砂丘の畑）。

## 音

BGMと効果音は、ブラウザの Web Audio で鳴らしています。音声ファイルは使っていません。
画面右上のボタンで、それぞれオン・オフできます。曲は、畑・月の畑・砂丘の畑・直売所でそれぞれ変わります。

## 動かし方

`index.html` をブラウザで開くだけで遊べます。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを選んでください。

## セーブ

進み具合は、ブラウザの localStorage に保存されます。別の端末やブラウザとは共有されません。
